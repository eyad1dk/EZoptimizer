# Security

Version 0.1.0 is an early preview.

Never post passwords, tokens, personal paths or private system reports in public issues. For a suspected vulnerability, use the repository's private vulnerability reporting feature if the owner has enabled it. Otherwise, contact the owner privately before disclosing details.

History files are local to the Windows user. Keep them until you have restored an active session. Changing or deleting them can prevent recovery.

Official release builds should come from this repository's Actions workflow. Compare the executable's SHA-256 hash to the release checksum before running a downloaded copy. A matching checksum confirms the file matches the attached release, not that the software is free of defects.
