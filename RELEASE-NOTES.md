# EZoptimizer 0.1.0 — Preview

The first public preview of EZoptimizer.

- Gaming, Coding, Everyday and Quiet profiles.
- Live CPU, memory and system-drive overview.
- Reviewed changes with durable history and verified undo.
- Process and startup inspection.
- Temporary keep-awake sessions for long tasks.
- Windows settings shortcuts and local system reports.

Download **EZoptimizer.exe** and launch it. No installer or separate .NET runtime is required. This release targets Windows x64 and is unsigned.

The initial local build passed eight simulated recovery checks and a read-only native smoke test on Windows 10 x64. Wider hardware testing is still needed. Results depend on workload; no FPS or build-speed improvement is guaranteed.

If you find an issue, include your Windows version, steps to reproduce it and the message shown by the app. Review reports for private information before sharing.
